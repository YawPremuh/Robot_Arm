### Workflow
1. Localize the target objects
2. Pick up the weigh boat
3. Place the weigh boat on the scale
4. Prompt user to enter desired amount of material to be added to the reactor
5. Pick up scoop
6. Scoop powder from the material container
7. Verify the measured mass
8. Transfer the material to the reactor once the target mass is reached
